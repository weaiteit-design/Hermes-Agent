# Manas AI Workspace

This repository is the shared working hub for Manas and Hermes Agent.

## Purpose

Use this repo to store durable context, active projects, tasks, launch plans, automations, research notes, and operating preferences.

## Core files

- `MANAS_PROFILE.md`: Durable personal and working preferences
- `PROJECTS.md`: Active projects and important context
- `TASKS.md`: Current task board and priorities
- `AUTOMATIONS.md`: Scheduled briefings, reminders, and workflow ideas
- `SETUP.md`: Existing setup notes

## Working style

- Concise first
- Details only when needed
- Proactive suggestions
- Result-focused technical updates
- Safe edits when intent is clear
- No fluff
- No overexplaining
- No em dashes

## Security

Secrets stay out of Git. `.env` is ignored by `.gitignore`.
