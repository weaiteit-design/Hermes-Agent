# Wedding Mini Milestones Planner Bundle

Thank you for your purchase. This is a digital download. No physical item will be shipped.

## What is included
- Wedding Mini Milestones Planner.md: the main planning guide with timelines, checklists, scripts, and workflows.
- Guest_Tracker.csv: track guests, RSVPs, gifts, dietary notes, and event attendance.
- Mini_Event_Budget.csv: budget template for engagement party, bridal shower, bachelor/bachelorette, rehearsal dinner, and welcome dinner.
- Vendor_Contact_Tracker.csv: vendor comparison and contact log.
- Day_Of_Run_Sheet.csv: simple timeline for mini events.
- Canva_Mockup_Prompt.txt: optional prompt to recreate listing-style mockups in Canva.

## How to use
1. Open the Markdown file in Notion, Google Docs, Apple Notes, or any markdown editor.
2. Upload CSV files to Google Sheets or Excel.
3. Duplicate tabs/sheets for each event you are planning.
4. Customize dates, names, budget categories, and vendor details.
