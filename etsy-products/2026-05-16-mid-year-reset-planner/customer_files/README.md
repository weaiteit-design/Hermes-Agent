## How to use the printable
1. Open `Mid_Year_Reset_Planner_Printable.html` in Chrome, Edge, Safari, or Firefox.
2. Choose **Print**.
3. Select **Save as PDF** or print on US Letter/A4.
4. Recommended print settings: scale 95–100%, background graphics ON, margins default or narrow.

## How to use the spreadsheets
1. Open Google Sheets.
2. Go to **File → Import → Upload**.
3. Upload the CSV file you want to use.
4. Choose **Insert new sheet(s)**.
