# Notion Copy Instructions

This bundle does not require a paid Notion template link. You can build a clean Notion version in under 5 minutes:

1. Open Notion and create a new page called **Mid-Year Reset Planner**.
2. Copy the contents of `Mid_Year_Reset_Planner_Workbook.md` into the page.
3. Create four simple databases if desired:
   - **Life Audit**: Life Area, Score, What is Working, Reset Step.
   - **90-Day Goals**: Goal, Why, Success Marker, First Action, Status.
   - **Habits**: Habit, Week, Completed, Notes.
   - **Budget Reset**: Category, Current Amount, Adjustment, Notes.
4. Import the CSV files into Notion by choosing **Import → CSV**.
5. Keep the workbook page as your dashboard and link each imported database below it.
